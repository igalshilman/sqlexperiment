# Amplification results — 2026-10-10

Storage format v12: a log of page images, pages checkpointed in place and a small checkpoint record, with adaptive LZ4 page envelopes. Each baseline is a bulk load followed by a save that checkpoints it, so reads reach page keys.

4,104 raw class/phase rows; 684 measured phases; 104 workload/cache configurations, 3 repeats each. Every counter agrees across repeats. Generated by `benches/scripts/analyze_amplification.py`.

See [README.md](README.md) for workload definitions and denominators. Cold totals include open. Warm totals include only the repeated query. Bytes count logical keys and values, without transport framing or physical replication.

## Cold-open baseline

Observed (meta gets, log probe gets, page gets, confirmation puts) during open: (1, 6, 1, 2), (1, 6, 5, 2). Open reads meta, probes the log in one batch and, on this weak simulated backend, re-puts the log tail and meta it did not write.
