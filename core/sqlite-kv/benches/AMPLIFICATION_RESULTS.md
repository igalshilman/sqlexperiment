# Amplification results — 2026-10-10

Storage format v14: one commit record holding the log since the last checkpoint (a large transaction's segments stored beside it), pages checkpointed in place, with adaptive LZ4 page envelopes. Each baseline is a bulk load followed by a save that checkpoints it, so reads reach page keys.

4,104 raw class/phase rows; 684 measured phases; 104 workload/cache configurations, 3 repeats each. Every counter agrees across repeats. Generated by `benches/scripts/analyze_amplification.py`.

See [README.md](README.md) for workload definitions and denominators. Cold totals include open. Warm totals include only the repeated query. Bytes count logical keys and values, without transport framing or physical replication.

## Cold-open baseline

Observed (commit record gets, stored segment gets, page gets, puts) during open: (1, 0, 1, 0), (1, 0, 6, 0). Open reads the commit record, and the stored segments its log names; it writes nothing.
